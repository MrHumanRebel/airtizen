Experimental AirTizen audio receiver UI for Samsung TVs.

This signed WGT is the UI only. It requires the separately installed native receiver service. A WGT alone does not receive AirPlay. No verified native service TPK or Tizen 3.0 video renderer is supplied by this workflow yet.

Screen mirroring, AirPlay video streaming, DRM video, AirPlay 2 multiroom and physical UE65MU6100 compatibility are not implemented or verified. Do not treat this prerelease as a production-ready full AirPlay receiver.

The signing profile must authorize the target Samsung TV. Keep the existing app author identity when updating an installed app. SHA256SUMS accompanies the artifact.
